# Bundled Font Licenses

Funke ships IBM Plex Sans Condensed Regular as its default font.

## SIL Open Font License 1.1

The font's embedded metadata identifies the SIL Open Font License,
Version 1.1. The full license text is in [OFL-1.1.txt](OFL-1.1.txt).

| Font file | Copyright | Source |
|---|---|---|
| `IBMPlexSansCondensed-Regular.ttf` | Copyright 2019 IBM Corp. All rights reserved. IBM Plex(R) is a trademark of IBM Corp. | [IBM Plex](https://github.com/IBM/plex) |

## Rubik

Rubik is bundled as upright and italic variable fonts (weight 300–900).
The original copyright notice and license are in [OFL-Rubik.txt](OFL-Rubik.txt).

| Font file | Copyright | Source |
