# Editor View Rendering

Open the **shaded sphere** in the Editor View's top-right toolbar, or **Edit > View > Rendering**. The popup controls the editing preview only. Game View, camera previews, scene assets, project graphics settings and builds retain their authored rendering. Renderer overrides are restored after each viewport pass.

| Control | 2D view | 3D view | Behavior |
|---|---|---|---|
| Lighting | — | Yes | Off uses unlit base colors and textures. Custom mesh shaders are bypassed while lighting is off because they may implement their own lighting. |
| Shadows | — | Yes | Gates the built-in directional shadow pass; requires Lighting and project/light shadow settings. |
| Fog | — | Yes | Gates the main camera's distance fog; it does not enable fog on a camera that has none. |
| Skybox | — | Yes | Hides the background sky without removing its ambient illumination. |
| 2D Scene Effects | Yes | With the 2D module | Gates registered package effects on 2D content, including Funke.Lighting2D lighting and shadows. Separate from camera post-processing. |
| Custom Material Shaders | Yes | Yes | Uses standard sprite/mesh rendering and procedural sky when disabled. Does not disable camera post-processing shaders. |
| Individual Shaders | Yes | Yes | Lists custom material shaders referenced by loaded scenes, or the prefab being edited. Uncheck a shader to use its standard fallback only in this preview. Hover for the full path. |
| Particles | Yes | Yes | Hides particle draws. Simulation and particle preview playback continue. |
| User Interface | Yes | Yes | Hides screen-space and world-space UI; selection tools remain available. |
| Grid and Axes | Yes | Yes | Hides the editing grid/axes independently of grid snapping. The 2D snap grid otherwise appears while snapping is enabled or Ctrl is held. |
| Post Processing | Yes | Yes | Shares the existing toolbar toggle for camera effects and anti-aliasing. |

Rendering switches and grid/UI visibility are saved as separate **2D and 3D user preferences**, shared across projects. Individual shader exclusions last only for the editor session. Post Processing retains its existing shared session toggle. The reset icon restores the current view mode's rendering defaults and enables Post Processing. The toolbar sphere is highlighted when that mode has rendering overrides.

The existing Default, Triangle (wireframe), and Mixed drawing modes remain available. Wireframe rendering already omits some filled passes, so effects that depend on shaded geometry may not appear there. Turning an option on permits the authored feature; it does not add lights, fog, shadows, particles or a sky to the scene.

Funke's core 2D renderer has no built-in 3D lighting, distance fog, or skybox. Package-based 2D lighting and shadows are therefore controlled together under **2D Scene Effects**, not through the 3D light/shadow controls.

The six view glyphs are generated by ImageGen. The original atlas and exact prompt are in `scripts/assets/sources/editor-imagegen/view_rendering_sheet.*`; `source_box` in the icon manifest selects each atlas cell. The exporter preserves the generated alpha contours, applies the standard white runtime tint base/padding, and writes 16/32/64/128 pixel PNGs.
