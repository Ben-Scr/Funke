Funke im Browser

Bearbeite die Szene im originalen Editor. ▶ startet das Spiel, ■ kehrt zur bearbeiteten Szene zurück. Strg+S speichert lokal in diesem Browser.

C# wird mit Roslyn im Browser kompiliert. Weise EntityScripts im Inspector oder über den Skript-Dialog einem Objekt zu. Öffne vorhandene Skripte auch per Doppelklick im Project-Bereich.

Projekt-ZIPs enthalten Szenen, Assets und Quellcode. Szenendateien allein enthalten keine externen Assets. Leere Browserdaten löschen lokale Projekte.

Desktop mit WebGPU erforderlich. Der Web-Export enthält die C#-Laufzeit und läuft auf statischem Webhosting. Native Erweiterungen, Desktop-/Mobil-Builds und Paketinstallation benötigen den Desktop-Editor.

Webspiel exportieren

Das ZIP enthält dein eigenständig lauffähiges Spiel: Szenen, Assets, kompilierte C#-Skripte und Laufzeit. Der Editor wird beim Spielen nicht angezeigt.

ZIP entpacken und den gesamten Inhalt auf statisches Webhosting laden. Lokal mit dem enthaltenen Startskript öffnen; ein Doppelklick auf index.html genügt für WebAssembly nicht.
