# Security Policy

## Supported versions

Until the first public release, fixes target the current `master` branch. After publication, only the latest release (including a beta) receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Use GitHub's private reporting instead:
[Report a vulnerability](https://github.com/Ben-Scr/Funke/security/advisories/new).

Include the Funke version, what an attacker could do, and steps or a file that reproduces it.

Areas where reports are especially useful: loading untrusted scene, prefab or project files; the package installer and registry downloads; the Launcher's Asset Library downloads; and the release signing and checksum verification.
